# Melegy AI — النسخة المستقلة القابلة للنشر (melegy.app)

دي نسخة كاملة ومستقلة من تطبيق Melegy AI، جاهزة للنشر على استضافة مجانية
وتتفتح لأي مستخدم بلينك عام على الدومين **melegy.app**:

- **الواجهة**: `public/index.html` — صفحة شات عربية (RTL) بنفس هوية ميليجي
  والأفاتار بتاعه، فيها قائمة محادثات، وتوليد صور من الوصف النصي بس
  (اطلب صورة في رسالة عادية وهتتولد على طول، أو استخدم وضع الصور من
  قائمة الزائد (+) — مفيش صور مرجعية ولا تعديل على صور)،
  ورفع ملفات Word وExcel وPDF وقراءتها والتعديل عليها، وتسجيل صوتي
  بيتحول لنص، وزر سماعة بيقرا كل رد بصوت مصري طبيعي، ودردشة صوتية
  مباشرة كاملة، وعارض صور مكبّر وزر تنزيل.
- **الباك إند**: `server.js` — سيرفر Node.js من غير أي مكتبات خارجية
  (Node 18 أو أحدث)، بيقدّم الواجهة وواجهة برمجية JSON، وبيشغّل محرك
  المحادثة (مع بحث لحظي على الإنترنت وقراءة روابط) ومحرك توليد الصور
  ومحرك قراءة المستندات وبناء نسخها المعدّلة ومحركَي التفريغ الصوتي
  والنطق بالعامية المصرية.
- **قاعدة البيانات**: SQLite مدمجة في Node (`node:sqlite`) وبتتخزن في
  `data/melegy.db`، ولو نسخة Node أقدم بيستخدم ملف `data/melegy.json`
  تلقائيًا. الصور المولّدة بتتخزن كملفات في `data/images` وبتتقدم من
  نفس السيرفر. كل زائر له محادثاته لوحده (كوكي عشوائي مجهول).

## الإعداد الوحيد المطلوب

متغير بيئة واحد بس، بيتحط في إعدادات الاستضافة ومش بيظهر في الصفحة أبدًا:

```
GEMINI_API_KEY=مفتاح خدمة الذكاء الاصطناعي بتاع الاستوديو
```

من غيره الموقع بيفتح عادي وبيرد برسالة صادقة إن الخدمة لسه بتتجهز.

## النشر على Render (مجاني) — الطريقة المقترحة

1. ارفع مجلد `standalone` ده في مستودع GitHub خاص بيك (هو جاهز:
   `package.json` و`render.yaml` موجودين).
2. في [Render](https://render.com): **New + → Blueprint** واختار المستودع،
   أو **New + → Web Service** بالإعدادات دي:
   - Runtime: **Node**
   - Build Command: (فاضي)
   - Start Command: `node server.js`
   - Instance Type: **Free**
3. في تبويب **Environment** ضيف `GEMINI_API_KEY` بقيمته.
4. بعد أول نشر هيبقى عندك لينك شغال شكله:
   `https://melegy-ai.onrender.com`

### حدود الخطة المجانية (بصراحة)

- السيرفر بينام بعد حوالي ١٥ دقيقة من غير زيارات، وأول زيارة بعده
  بتاخد لحد دقيقة على ما يصحى.
- نظام الملفات مؤقت: المحادثات والصور المحفوظة بتتمسح مع كل إعادة نشر
  أو إعادة تشغيل. للاحتفاظ الدائم اربط **Render Disk** (مدفوع) أو انقل
  لنفس الكود على استضافة بقرص دائم.

## ربط الدومين melegy.app

1. في Render افتح الخدمة → **Settings → Custom Domains → Add Custom Domain**
   وضيف الدومينين: `melegy.app` و`www.melegy.app`.
2. Render هيديك قيمة CNAME هدف لكل دومين (شكلها `melegy-ai.onrender.com`).
3. في لوحة تحكم الدومين (المسجّل اللي اشتريت منه melegy.app) ضيف
   سجلات DNS دي:

| النوع | الاسم (Name) | القيمة (Value) |
|---|---|---|
| CNAME | `www` | `melegy-ai.onrender.com` |
| ALIAS / ANAME | `@` (الجذر) | `melegy-ai.onrender.com` |

- لو المسجّل مفيهوش ALIAS/ANAME للدومين الجذري: انقل إدارة DNS لـ
  **Cloudflare** (مجاني) — بتغيّر الـ Nameservers عند المسجّل لقيم
  Cloudflare، وبعدين تضيف في Cloudflare سجل **CNAME** للجذر `@` بنفس
  القيمة (Cloudflare بيعمل CNAME Flattening تلقائيًا)، وسجل CNAME
  لـ `www` بنفس القيمة.
- الانتشار بياخد من دقايق لحد ٢٤ ساعة، وRender بيصدر شهادة HTTPS
  تلقائيًا بعد ما الـ DNS يوصل له. النتيجة النهائية: الموقع بيفتح من
  `https://melegy.app`.

## بدائل مجانية بنفس الكود

- **Railway / Koyeb / Fly.io**: نفس الخطوات تقريبًا — ارفع نفس المجلد،
  Start Command هو `node server.js`، وضيف `GEMINI_API_KEY`، وبعدين
  اربط الدومين من إعدادات الخدمة وهتاخد قيمة CNAME مختلفة تحطها في
  الـ DNS بنفس الطريقة.

## تشغيل محلي للتجربة

```bash
GEMINI_API_KEY=... node server.js
# افتح http://localhost:3000
```

بيشتغلوا بكلاينت OAuth مسجل على رابط Muse، فمش منقولين في النسخة
المستقلة دي. لو حبيت تفعّلهم هنا: سجّل في Google Cloud Console
الـ Redirect URI الجديد `https://melegy.app/` على نفس الكلاينت،
وساعتها يتنقلوا بنفس الطريقة.
